Privacy notice · Beta

Your expenses
stay yours.

FairShare stores only the information needed to operate shared groups. This beta does not sell data, show ads, or use financial information for marketing.

Information we process

  • Your verified email, display name, optional profile image, and sign-in identifier.
  • Groups, memberships, expenses, payer contributions, shares, settlements, schedules, and activity history you create.
  • Notification device tokens and basic operational logs needed to keep the service reliable.

Service providers

Firebase provides authentication and push messaging. Render hosts the API. Neon stores PostgreSQL data. Cloudinary stores optional profile images. GitHub distributes the app and hosts this page.

Account deletion

You can delete your account from the app. Your personal profile and device tokens are removed. Financial entries already shared with a group are retained under an anonymized “Deleted user” identity so other members’ balances remain accurate.

Security and beta limits

Traffic uses HTTPS and access is restricted to authenticated group members. This is a small public beta running on free service tiers, so it has no uptime or backup guarantee.

Contact

Open an issue in the FairShare GitHub repository for privacy questions or data requests.
